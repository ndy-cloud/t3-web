# EngageLab × T3 出行香港业务解决方案

面向 T3 出行香港市场的独立静态 Web 提案，聚焦三项产品：

- EngageLab AppPush
- EngageLab SMS
- 极光认证 JVerification 香港一键登录（Android、iOS）

## 本地预览

直接打开 `index.html`，或在本目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 文件

- `index.html`：页面内容与结构
- `styles.css`：响应式视觉与动效
- `app.js`：响应式导航与滚动显现
- `assets/t3-hong-kong-hero.jpg`：AI 生成的香港出行首屏视觉
- `assets/t3-jverification.jpg`：AI 生成的香港号码登录场景视觉
- `assets/hong-kong-data-center.jpg`：AI 生成的香港数据中心场景视觉

## 方案范围

页面面向 T3 出行香港业务，覆盖一键登录、AppPush、SMS、行业案例、节点选择与验证计划。
